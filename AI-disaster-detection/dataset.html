DATASET

Disaster Image Dataset

Dataset used for training, validation and testing of the disaster classification model.

DATASET OVERVIEW

AIDER Split Dataset

● Ready

The project uses the AIDER Split image dataset for disaster scene classification. The dataset is divided into separate training, validation and testing sets.

Images are organized into five classes and are processed before being given to the ResNet50 Deep Learning model.

DATA PREPROCESSING

Image Preparation

Step 1 📂 Load Images

Images are loaded from their respective class folders.

Step 2 📐 Resize

Each image is resized to 224 × 224 pixels.

Step 3 ⚙️ Preprocess

ResNet50 preprocessing is applied to the image data.

Step 4 🧠 Model Input

Preprocessed images are passed to ResNet50.
