DEEP LEARNING MODEL

ResNet50 Disaster Classification

A transfer learning based Deep Learning model for detecting disaster-related scenes from images.

MODEL OVERVIEW

ResNet50

● Ready

The system uses ResNet50, a convolutional neural network architecture, with Transfer Learning using ImageNet-pretrained weights.

The original ResNet50 classification layer is replaced with a new classification layer designed for the five disaster-related classes in the project dataset.

MODEL CONFIGURATION

Model Details

Architecture ResNet50
Learning Technique Transfer Learning
Input Size 224 × 224 × 3
Number of Classes 5
Optimizer Adam
Epochs 10
Batch Size 16
Learning Rate 0.0001
Activation Softmax
MODEL PIPELINE

How the Model Works

Step 1 📷 Input Image

User uploads a disaster-related image.

Step 2 ⚙️ Preprocessing

Image is resized to 224 × 224 pixels and preprocessed for ResNet50.

Step 3 🧠 ResNet50

The pretrained network extracts important visual features.

Step 4 🔍 Classification

The model predicts one of five disaster classes.

OUTPUT CLASSES

Disaster Categories

Class 1 Fire

Images containing fire or fire-related scenes.

Class 2 Flooded Areas

Images showing flooded or water-affected areas.

Class 3 Normal

Images without the targeted disaster conditions.

Class 4 Collapsed Building

Images showing damaged or collapsed structures.

Class 5 Traffic Incident

Images showing traffic incidents or related situations.

DEPLOYMENT

Prediction System

● Active

The trained model is saved as disaster_resnet50.keras and is connected to the Flask prediction API.

When a user uploads an image through the Detection page, the Flask backend preprocesses the image, passes it to the ResNet50 model and returns the predicted class, confidence and risk level.
